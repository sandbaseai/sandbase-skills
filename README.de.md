**88 installierbare Agent Skills** — Für Recherche, Social Intelligence, Marketing und Business-Workflows. Ein API-Schlüssel. Alle Datenquellen. In jeden kompatiblen Agent (Claude Code, Codex, Cursor, Gemini CLI) installieren und sofort loslegen.

## Schnellstart

```bash
# 1. SandBase API-Schlüssel setzen
export SANDBASE_API_KEY='sk-...'

# 2. Einen Skill installieren
npx skills add sandbaseai/sandbase-skills --skill twitter-intelligence --agent codex

# 3. Nutzen
# "Recherchiere, was Leute diese Woche über [Marke] auf Twitter sagen"
```
