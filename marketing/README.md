# Marketing and Workflow Skills

This directory contains the expanded workflow collection: content and SEO,
software engineering, data analysis, media generation, cloud operations, and
business operations. Each Skill is self-contained and starts at its
`SKILL.md` file.

## How to find a Skill

- Browse the [catalog metadata](../catalog/skills/), which is the authoritative
  install list and includes each Skill's display name and description.
- Use the root [README catalog](../README.md#skill-catalog-245-skills) for
  task-oriented examples and domain groupings.
- Install a Skill by its path, for example:

  ```bash
  npx skills add sandbaseai/sandbase-skills --skill marketing/video-generator --agent codex
  ```

Keep new general-purpose workflows under this directory and keep the directory
name, catalog entry, and registry manifest path identical.
