# SandBase Scholar API Map

Use these tools through the SandBase gateway. Before each call, use `sandbase_describe_tool` to obtain current parameters, then use `sandbase_call_tool` with the exact tool name.

| Tool name | Use it for |
|---|---|
| `scholar_search_scholar` | Search academic papers and scholarly articles. |
| `scholar_search_web` | Search web content with academic focus. |
| `scholar_search_mixed` | Combined academic + web results (recommended default). |
| `scholar_explain` | AI-powered explanation with confidence scoring. |

Cite all papers with full attribution. Note publication dates and source quality.
