# SandBase

Use the configured SandBase MCP server to complete the user's request.

1. List the available SandBase MCP tools when the suitable tool is unknown.
2. Select the smallest suitable tool and explain any meaningful failure clearly.
3. Do not change unrelated local configuration or credentials.

Examples:

- `/sandbase` — inspect the available SandBase tools before choosing a workflow.
- “Use SandBase to get the latest information about …”
- “Use SandBase to create a presentation about …”
