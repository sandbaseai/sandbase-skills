# Security Policy

## Supported versions

Security fixes are applied to the latest released Skill pack and to `main`.
Install from the latest release before reporting an issue that may already be
fixed.

## Report a vulnerability privately

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/sandbaseai/sandbase-skills/security/advisories/new)
so the maintainers can investigate before details are disclosed.

Include the affected Skill, version or commit, reproduction steps, expected
impact, and any suggested mitigation. Remove credentials, tokens, and personal
data from the report.

Reports involving prompt injection, unsafe scripts or commands, unexpected tool
escalation, secret exposure, untrusted content handling, or supply-chain
compromise are especially useful. We will acknowledge the report when it is
triaged and keep the reporter informed as a fix and coordinated disclosure plan
are developed.
